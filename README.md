## 📌 Sobre o Projeto

Este é um sistema de gerenciamento hoteleiro desenvolvido em Java. O objetivo principal foi aplicar na prática o que estudei sobre a linguagem, saindo dos exercícios básicos e construindo algo com lógica de negócio real.

O sistema permite simular as operações do dia a dia de um hotel, focando na organização de quartos, hóspedes e estadias.

## 🚀 O que eu pratiquei/aprendi:

- **Orientação a Objetos (POO):** Uso de classes, objetos, encapsulamento e herança.
- **Estruturas de Dados:** Manipulação de listas (ArrayList) para gerenciar quartos e hóspedes.
- **Lógica de Programação:** Implementação de regras de negócio (check-in, check-out, cálculo de diárias).
- **Interação via Console:** Entrada e saída de dados de forma organizada.

## 🛠️ Funcionalidades (Exemplos)

- [x] Cadastro de Hóspedes.
- [x] Gerenciamento de Quartos (Disponível/Ocupado).
- [x] Realização de Reservas/Check-in.
- [x] Cálculo automático do valor da estadia no Check-out.
